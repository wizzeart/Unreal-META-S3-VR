# Matrix VR Show para Meta Quest 3S

Paquete Android ASTC de Matrix VR Show, generado el 15 de octubre de 2026. Incluye APK, OBB y cinco archivos de `Content/Paks`; `SHA256SUMS.txt` comprueba su integridad.

Con Quest conectada y autorizada por ADB, ejecuta `Tools\cmd\instalar-matrix-vr-show.bat` desde la raíz del repositorio. Instala sobre el mismo identificador `com.Allnovu.testMeta` y conserva `Houses/`, modelos y partidas. La app se abre luego desde la biblioteca del visor sin computadora; el hub local solo se necesita para consultar o descargar modelos de la laptop.

La interfaz, el icono y las pantallas de arranque usan la identidad ciberpunk con el nombre Matrix VR Show. Esta revisión oculta la geometría del mapa de ejemplo antes de abrir el menú inicial para evitar que el suelo tape sus botones. El menú y sus botones se comprobaron visualmente en Quest 3S el 15 de octubre de 2026. Los paquetes anteriores de `quest3s-test-actual`, `quest3s-visual-candidate` y `quest3s-casas-vr` permanecen intactos.
